# Documentation Architecture : Riviera Tower Supervision App

## 1. Stack Technique
- Vanilla HTML / CSS / JavaScript.
- Pas de framework JS (ni React, ni Vue). Manipulation directe du DOM.
- Firebase Firestore (compat 9.22.2) pour la persistance et synchro temps réel (`docRef = site_charts/current_week`).
- SortableJS (avec MultiDrag activé) pour le Drag & Drop.
- SheetJS pour import/export Excel.

## 2. Rôles et Permissions (`currentRole`)
- **viewer** : Lecture seule, aucun bouton d'édition ou de déplacement visible.
- **timekeeper** : Peut déplacer les ouvriers et imprimer, mais ne peut pas modifier les effectifs cibles (`workers`) ni les coûts/payroll.
- **cfo** : Peut modifier les effectifs cibles et le Payroll, mais ne peut pas réorganiser le chantier.
- **admin** : Tous les droits, y compris la configuration des entreprises et l'import de pointages de masse.

## 3. Structure des Données Principales
### L'objet `cardsData` (Array d'équipes/superviseurs)
Chaque objet représente une équipe :
- `name` (String) : Nom du Superviseur
- `manager` (String) : Nom du N+1
- `category` (String) : Lot de travaux (civil, trades, facade, logistic, external, indirect, plant)
- `timesheetNo` / `timesheetName` / `shiftType` / `shiftHours` (Strings) : Infos pour l'impression.
- `printTasks` (Array of Strings) : Les colonnes personnalisées pour l'impression des Timesheets.
- `tasks` (Array d'objets) : Les sous-équipes ou tâches.
   - `foreman` (String) : Chef d'équipe
   - `desc` (String) : Description de la tâche
   - `source` (String) : Entreprise sous-traitante
   - `workers` (Number/String) : Effectif manuel "forcé" (cible)
   - `workerList` (Array d'objets) : Les ouvriers réellement assignés (id, name, company)

### L'objet `unassignedWorkers`
Tableau d'objets ouvriers `{ id, name, company }` qui sont dans la base de données mais pas encore glissés dans une carte `task`.

### L'objet `siteCompanies`
Tableau de strings listant les sous-traitants (ex: 'SKYBUILDING', 'DSS').

## 4. Fonctionnalités Implémentées (À ne pas recréer)
- MultiDrag SortableJS fonctionnel entre le Drawer et les tâches.
- Modale "Base Globale" avec nettoyage de doublons intelligent.
- Algorithme d'impression paginé par 15 lignes, sur 6 jours (Lundi à Samedi), générant du HTML envoyé vers `window.print()`.
- Filtres dynamiques combinés (Catégorie + Multi-select Manager + Multi-select Superviseur).
